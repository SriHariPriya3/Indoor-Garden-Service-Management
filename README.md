 Indoor Garden Service Management (IGSM)

 About the Project:

Indoor Garden Service Management (IGSM) is a custom ServiceNow application developed to manage indoor gardening service requests.
The application allows users to submit requests through a Service Portal and supports approval, task management, SLA tracking, automation, and role-based security.

 Key Features:

 Garden service request management
 Garden Record Producer
 Flow Designer approval workflow
 Response and Completion SLAs
 Business Rule and Catalog Client Script
 Role-based ACL security
 Task and request tracking

 Technologies:

- ServiceNow
- ServiceNow Studio
- Flow Designer
- Service Portal
- JavaScript
- SLA Management
- ACL Security

 Roles:

- Requester
- Technician
- Manager

 Project Status:

**Completed and ready for demonstration.**
